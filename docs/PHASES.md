# MVP Phase Plan and Acceptance Ledger

| Phase | Goal | Required evidence |
| --- | --- | --- |
| 1 | Foundation | runnable health endpoint, web shell, authority docs |
| 2 | Core data | versioned models, migrations/schema tests |
| 3 | Character library | CRUD, import/export, share/fork tests |
| 4 | Scenario creator | location/routes and validation tests |
| 5 | Lobby | join/ready/manifest lock tests |
| 6 | Simulation | deterministic route, encounter and event tests |
| 7 | Player | playback/timeline/A-B UI tests |
| 8 | Branching | snapshots/interventions/divergence tests |
| 9 | Runtime safety | masked credentials/provider abstraction tests |
| 10 | Art | art bible, manifests, contact sheets, fallback validation |
| 11 | Admin | authorization-aware summaries and audit tests |
| 12 | Quality | complete test report, smoke test, deployment and handoff notes |

All phase commits are intended to be pushed to `main`. The current execution environment lacks a writable GitHub remote/`gh`; see TAKE-NOTE.
